# Do Not Suggest

Block unnecessary suggestions and questions in ChatGPT responses.

The initial target is ChatGPT Chat. Contextual relevance alone does not make a suggestion or question wanted.

## ChatGPT Web Filter

The `web-filter/` companion is a Chrome Manifest V3 content filter for ChatGPT web. It hides a matching unsolicited solicitation when it appears as the final non-empty paragraph or list item in an assistant message. This client-side layer works independently of model instructions and does not apply to the ChatGPT mobile apps.
